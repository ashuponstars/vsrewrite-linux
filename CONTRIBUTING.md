# contributing

fixes are welcome. you don't need to fork anything.

- **small fix:** open an issue with the "fix / patch" template and paste your diff. i'll apply it and credit you in the commit
- **bigger change, or you want to keep working on it:** ask for collaborator access in an issue, then push a branch and open a pull request
- **bug with no fix:** use the "bug report" template and attach `vsrewrite-log.txt`

please say what distro / desktop you tested on. keep changes small and focused, one fix per patch. code lives in `source/`, building is in [BUILDING.md](BUILDING.md). the mod itself (`mods/Sonic`) belongs to its creators, so don't send changes to it here.
